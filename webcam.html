The miner uses chronological discovery and confirmation sets plus shuffled-outcome controls. It proposes correlations only. No latch is installed without separate predictive validation or intervention; shuffles are not Model-X knockoffs.

Privacy: all processing is local JavaScript. No webcam frames are sent to a server; audit JSON contains numerical metrics, coarse archived tile signals and feature scores, but no reconstructable camera images by default. The archive retains only the most recent 512 low-resolution frames in memory and clears on reset/reload. Camera requires HTTPS or localhost (use the included Windows launcher).
